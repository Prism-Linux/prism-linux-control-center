# Source provenance

Prism Linux Control Center is prepared as a separately maintained derivative of [Lian Li Linux](https://github.com/sgtaziz/lian-li-linux), not as a claim that its existing code was originally created for Prism.

- The working history's upstream base is `896593b3b84f0d9225471222a319c4c95144c635`.
- `LICENSE` retains the upstream copyright notice for `sgtaziz` and the MIT terms. It also identifies Major Riven's original Prism contributions as MIT-licensed. File-level notices for copied upstream and third-party material remain in place.
- The project is separately maintained. The local Git history and private preparation records are intentionally not included in the publication snapshot. Git author metadata is not, by itself, a legal determination of copyright ownership.
- The prepared source tree omits private Git history, private preparation records, machine-specific artifacts, the Lancool 207 A5 template whose redistribution permission was not established, and other previously excluded uncleared artwork. The source tree is based on the sanitized v1.3.0-beta.1 candidate; this repository starts with its own history.
- Cargo metadata from the exact locked Rust dependency sources and the frontend lockfile are summarized in `THIRD_PARTY_NOTICES.md`. The inventory records declared license expressions; it is not a legal opinion or a claim about system libraries linked by a particular build.
