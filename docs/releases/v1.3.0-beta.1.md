# v1.3.0-beta.1 release notes

Prism Linux Control Center is a separately maintained derivative of Lian Li Linux. Original upstream and third-party notices are retained. See [NOTICE](../../NOTICE) and [source provenance](../../SOURCE_PROVENANCE.md).

## Highlights

- Linux RGB and hardware control through the existing eight-page GUI and daemon.
- Fan and pump management, motherboard PWM synchronization and LCD media playback for supported hardware.
- Native RGB controls for the exact Gigabyte AORUS RTX 4080 XTREME WATERFORCE WB with Static and Rainbow Wave effects. The owner physically verified operation after the GUI dispatch repair.
- ENE-based G.Skill DDR5 RGB support has owner-verified Static, Breathing, Rainbow, Off, Direct colors and saved Rainbow restoration.
- Stable builds continue checking only stable releases. Beta builds check prerelease and stable releases so they can update to the next beta or the stable release.

## Compatibility and limitations

Device support is model and connection specific; see the [hardware compatibility guide](../hardware-compatibility.md). The RTX 4080 backend supports Static and Rainbow Wave only. ASUS motherboard T_SENSOR mapping remains unsupported on the tested board, ASUS Aura physical output and some wireless/LCD paths remain unverified, and suspend/resume validation remains deferred.

This first beta is intended for community feedback and hardware compatibility testing. Install only the Debian package matching your distribution, verify its SHA256 checksum, and follow the [installation and upgrade instructions](../installation.md). Additional hardware support requires device-specific implementation and verification; discovery of a device alone does not establish support.
